1.4 SECTION 3: MCMC BAYESIAN POSTERIOR DISTRIBUTIONS

This section uses Markov Chain Monte Carlo (Metropolis-Hastings algorithm) to estimate the TRUE underlying win rate and mean return, accounting for sampling uncertainty.

MCMC Implementation (Pure TypeScript, Runs in Browser):
Implement a Metropolis-Hastings sampler from scratch. Do NOT use any external MCMC library.

Target Parameter 1: TRUE WIN RATE
  - Prior: Beta(alpha=2, beta=2) — weakly informative, centered at 50%
  - Likelihood: Binomial(N_wins, N_total, theta) where theta is the true win rate
  - Proposal distribution: Normal(current_theta, 0.02) truncated to [0, 1]
  - Run 5 chains, each with 10,000 iterations (burn-in: 2,000, thin: 5)
  - Calculate: posterior mean, 95% credible interval, standard deviation, effective sample size (ESS)
  - Convergence diagnostic: Gelman-Rubin R-hat statistic (must be < 1.1 for convergence)
  - Display: posterior density as a smooth curve (Recharts AreaChart with 100 bins), vertical ReferenceLines at 95% CI bounds, vertical ReferenceLine at 50% (null hypothesis)
  - Text: "With 95% posterior probability, the true win rate is between X% and Y%"

Target Parameter 2: TRUE MEAN RETURN
  - Prior: Normal(0, 0.02) — we believe true mean return is near zero (weak prior)
  - Likelihood: Normal(actual_returns_mean, observed_std / sqrt(N))
  - Same MCMC machinery, adapted for continuous parameter
  - Display: posterior density, 95% CI
  - Text: "With 95% posterior probability, the true mean return per signal is between X% and Y%"
